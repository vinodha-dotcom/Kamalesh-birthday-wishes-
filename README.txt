BOYFRIEND BIRTHDAY WEBSITE ❤️

Included:
- index.html
- photos/photo1.jpg ... photo4.jpg
- Romantic countdown to 15 September 2026
- Love letter and memories
- Surprise button + heart animation
- Music button

MUSIC:
The package does not include copyrighted music. If you have a legally obtained
instrumental audio file, rename it to "music.mp3" and place it beside index.html.

HOW TO TEST:
Open index.html in a browser.

HOW TO PUT ONLINE FOR FREE:
Use GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository.
3. Upload index.html and the photos folder (and music.mp3 if you have one).
4. In Settings -> Pages, choose Deploy from branch -> main -> /root.
5. GitHub will give you a shareable website link.

NOTE:
The countdown is set for 15 September 2026 (India time, UTC+5:30).
